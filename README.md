# Flarum HTML Errors

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Flarum](https://img.shields.io/badge/Flarum-%5E2.0-brightgreen)

一个为 Flarum 论坛提供高度自定义 HTML 错误页面的插件。抛弃 Flarum 默认单调的错误提示，让你的 404、500 直接跳转到对应的网页。

## 安装

在 Flarum 根目录下运行以下 Composer 命令：

```bash
composer require tacraft-sociality/flarum-html-errors
